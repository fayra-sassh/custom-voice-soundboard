# 自定义语音播放器

Windows 桌面独立语音播放器。可自由增删语音条目，自定义键盘单键、鼠标键和语音文件；内置莫伊拉六条默认配置。

## 下载和使用

[下载 Windows 64 位便携版](https://github.com/fayra-sassh/custom-voice-soundboard/releases/tag/v5.0.0)。

完整解压 Release 中的 ZIP，双击 **启动播放器.cmd** 或 **MoiraSoundboard.exe**。保留整个文件夹，无需安装 Python，无需联网。
支持 Windows 10/11 64 位，使用系统 .NET Framework 4.x。

点 **按键和语音设置… → 新增语音**，设置名称、按键和音频，然后保存并应用。条目不再限于六条。

- 点按一次：松开也播完。
- 按住循环：松开停止，循环首尾交叉淡化。
- 选择后点按：先按前置键，再按选择键，只播放一次。例如 E → 鼠标左键。
- 每条可停用或删除；多个语音支持叠加混音。
- 支持 MP3、WAV、OGG、FLAC、M4A 等本地文件，每段 0.1–120 秒；导入时自动生成副本，原文件不改动。
- 支持键盘单键和鼠标左/右/中/侧键，暂不支持组合键。
- 保存立即生效，下次打开保留；上一次配置自动备份。

## 游戏中使用

默认仅在守望先锋前台自动触发。程序不改变游戏键位，请自行让两边设置一致。
默认左/右键按住循环，Shift/Q 点按，E → 左/右键选球后点按；F8 暂停/恢复，Enter 聊天暂停，Esc 取消选择。
菜单、死亡、换英雄时请手动暂停。

优先让游戏与播放器都使用普通权限。游戏已使用管理员权限时，可通过 **同游戏权限启动.cmd** 的 Windows UAC 提示匹配播放器权限。
该入口仅重开当前文件夹的播放器，不修改或退出游戏。

这是额外播放音效，原游戏语音保留。不改游戏文件，不访问游戏进程，不注入，不发送游戏按键。
工具没有暴雪认证，无法保证零封号风险。

## 源码编译

仓库包含 C# 源码和默认 WAV 素材，转换器与可运行 EXE 位于 Release ZIP。

1. 将 Release ZIP 中的 `.tools` 文件夹复制到源码目录，以提供音频导入功能。
2. 复制 `config.example.json` 为 `config.json`。
3. 在 Windows PowerShell 中运行 `./build.ps1`，再打开生成的 `MoiraSoundboard.exe`。

编译使用 Windows .NET Framework 自带 C# 编译器，不下载 NuGet 包。基本播放不需要转换器，导入新音频时才调用随附 FFmpeg。

`MoiraSoundboard.cs`：主界面与输入规则；`AudioMixer.cs`：PCM 混音和事件通知输出；`Customization.cs`：编辑器、持久化和导入。
默认素材和自定义素材的权利仍归各自权利人，第三方组件来源与许可见 `licenses`。
